Key Conflict — Least Privilege (AC-6)

NIST AC-6

"Employ the principle of least privilege, allowing only authorized accesses for users and processes necessary to accomplish assigned tasks."

Principle-based — does not prescribe Kubernetes-specific enforcement mechanisms.

CIS K8s 5.1.x

  • 5.1.1: Minimize cluster-admin usage
  • 5.1.2: Minimize access to secrets
  • 5.1.3: Minimize wildcard in Roles
  • 5.1.5: Default SA not actively used
  • 5.1.6: SA tokens only where necessary

Operationally verifiable, specific RBAC checks.

Resolution: CIS K8s 5.1.x applied as more restrictive — each check has a defined pass/fail criterion directly auditable against RBAC bootstrap policies in plugin/pkg/auth/authorizer/rbac/bootstrappolicy/.
